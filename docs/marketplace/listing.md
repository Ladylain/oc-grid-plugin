## Short description

Display the backend lists as a grid of cards: a drop-in replacement for the ListController with filters, search, sorting, bulk actions and drag and drop reordering.

## Keywords

backend, list, grid, cards, card view, gallery, ListController, list widget, reorder, sortable, dashboard, admin, UI
